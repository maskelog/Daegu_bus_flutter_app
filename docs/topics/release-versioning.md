# 릴리스 버전 관리

> 이 문서는 **현재 상태**를 서술한다. 변경 이력은 [devlog.md](../devlog.md)를 참조한다.
> 마지막 갱신: 2026-07-15

## 현재 버전

- 사용자 표시 버전(`versionName`): `1.0.4`
- 다음 내부 테스트용 빌드 번호(`versionCode`): `66`
- Flutter 선언: `pubspec.yaml`의 `version: 1.0.4+66`

## 배포 상태

`1.0.4+65`는 Google Play 전체 출시와 실기기 검증이 완료됐다. 지도에서 홈 화면으로
정류장 도착 정보를 여는 흐름과 홈 정류장 즐겨찾기 별표가 정상 표시된다.

단일 48dp 지도 액션 카드 변경을 포함한 `1.0.4+66` AAB는 로컬 빌드·서명까지
완료됐다. Play Console 업로드와 배포는 아직 기록되지 않았다.

릴리스 작업은 아래 상태를 순서대로 기록한다. **빌드 성공은 업로드나 배포 완료를 뜻하지
않는다.**

1. `준비`: `pubspec.yaml` 버전과 변경 범위를 정함
2. `빌드됨`: 서명된 AAB를 생성하고 분석·테스트를 통과함
3. `업로드됨`: Play Console이 번들을 수락함
4. `배포됨`: 내부 테스트 트랙에서 테스터가 설치할 수 있음
5. `검증됨`: Play 배포본을 실기기에 설치해 핵심 변경을 확인함

상태가 바뀌면 [devlog.md](../devlog.md)에 날짜·대상 `versionCode`·Console 결과를
append하고, 이 절을 현재 상태로 갱신한다.

## 규칙

- `build_release.ps1`은 별도 인자가 없으면 `pubspec.yaml`의 `version`을 읽어 AAB 또는
  APK의 `build-name`과 `build-number`로 전달한다.
- Google Play에 한 번 사용한 `versionCode`는 다시 사용할 수 없으며, 후속 업로드는
  이전 코드보다 큰 값을 사용한다.
- 표시 버전이 `1.0.3`에서 `1.0.4`로 바뀌더라도 내부 코드를 `1`로 초기화하지 않는다.
  `1.0.3+63` 다음 업로드는 `1.0.4+64`다.
- Play Console의 릴리스 이름은 앱 번들의 버전 값과 별개이므로 필요하면 `1.0.4 (1)`처럼
  관리용 이름을 사용할 수 있다.

## 빌드

- Play Store AAB: `.\build_release.ps1`
- 실기기용 APK: `.\build_release.ps1 -Apk`

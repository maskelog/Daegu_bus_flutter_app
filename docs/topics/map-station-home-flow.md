# 지도 정류장 선택 → 홈 전환

> 이 문서는 **현재 상태**를 서술한다. 변경 이력은 [devlog.md](../devlog.md)를 참조한다.
> 마지막 갱신: 2026-08-29

## 사용자 흐름

- 지도에서 도착 정보 조회가 가능한 정류장 마커를 선택하면 버스핀 팝업에 정류장 정보가
  표시되고, 지도 하단에는 `도착정보 보기` 액션과 닫기 버튼만 표시된다.
- 하단 액션은 시각적으로 정류장명을 반복하지 않지만 TalkBack 의미 레이블에는 선택한
  정류장명을 포함한다.
- 액션 카드는 내부 버튼 상자 없이 하나의 바깥 표면만 사용한다. 왼쪽 `홈 아이콘 +
  도착정보 보기` 영역은 Material 리플이 있는 `InkWell`, 오른쪽은 독립된 닫기 버튼이다.
- 카드와 두 터치 영역의 높이는 48dp다. 레이블은 한 줄로 유지하며 닫기 아이콘은
  20dp로 표시한다.
- 빈 지도 또는 닫기 버튼을 누르면 액션 카드가 닫힌다.
- 홈 화면에 임베드된 지도에서는 `onShowStationOnHome` 콜백으로 홈 탭을 선택하고 해당
  정류장의 도착 정보를 표시한다.
- 노선도에서 push된 지도에서는 선택한 `BusStop`을 Navigator 결과로 반환한다. 노선도
  화면이 그 결과를 받아 자신의 `onShowStationOnHome` 콜백으로 전달하거나 상위 화면으로
  다시 반환한다.
- 홈의 지도/노선도 탭은 선택됐을 때만 생성한다. 앱의 기본 홈 탭에서는 Kakao WebView를
  미리 만들지 않으며, 다른 탭으로 이동하면 지도 위젯과 그래픽 리소스를 해제한다.

## 구현 위치

- `lib/screens/map_screen.dart` — 마커 선택 상태, 액션 카드, 콜백/결과 반환
- `lib/screens/route_map_screen.dart` — push된 지도의 `BusStop` 결과 전달
- `lib/screens/home_screen.dart` — 홈/노선도 탭의 콜백 처리와 선택 정류장 갱신

## 메모리 정책

- 지도 화면의 주변 정류장 캐시는 12개, 도착 정보 캐시는 24개, 정류장 ID 캐시는
  100개까지만 유지한다. 삽입 순서상 가장 오래된 항목부터 제거한다.
- 앱이 background/cached 상태로 이동하거나 시스템 메모리 압박 콜백을 받으면 지도
  런타임 캐시를 비우고 노선 버스 위치 타이머를 중지한다. foreground 복귀 시 현재
  화면이 노선 지도인 경우에만 타이머를 다시 시작한다.

## 유효 정류장 조건

- 도착 정보를 조회할 수 있는 유효한 stationId가 확정된 정류장만 액션 카드에 반영한다.
- 지도 데이터에 stationId가 없으면 API 검색 fallback으로 정류장을 확정한 뒤 카드 상태를
  갱신한다.

## 검증 상태

- 지도 마커 선택 → `도착정보 보기` → 홈 탭 전환 → 선택 정류장 도착 정보 표시 흐름은
  Galaxy S25 Ultra(Android 16 / One UI 8, `1.0.3+63` APK 기준)와 Galaxy Note10+
  (`1.0.4+66` 로컬 sideload 기준, 2026-07-25)에서 확인했다.
- 내부 버튼 상자를 제거한 단일 48dp 카드 변경은 위젯 테스트와 `1.0.4+66` 실기기
  sideload 확인(2026-07-25)까지 마쳤다. Play 배포본에서의 실기기 확인은 아직
  남아 있다 (`docs/topics/follow-up-status.md` 참조).
